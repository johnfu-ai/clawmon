## 0. 全局骨架（所有页面共享，约束 1 的载体）

```text
┌───────────────────────────────────────┐
│ ◆ clawmon          ●2 ●1 ●1 ●1        │ 顶栏 36：品牌 + 四色汇总（点击汇总项=跳会话页）
├───────────────────────────────────────┤
│ [ 会话 ] [ 任务 ] [ 用量 ] [ 设置 ]     │ 主导航 40：四页一致，仅高亮不同
├───────────────────────────────────────┤
│ ⚠ WSL 连接异常，正在重试…（可选 28）   │ 警告横幅：有 warning 才渲染，位置固定
├───────────────────────────────────────┤
│                                       │
│           页面内容区（滚动）            │
│                                       │
├───────────────────────────────────────┤
│ ● 监控正常    5h 17%·7d 21%    21:34  │ 底栏 28：状态 · 用量芯片 · 时钟
└───────────────────────────────────────┘
```

| 区域 | 规则 |
|------|------|
| 顶栏 | 品牌恒左；四色汇总恒右，仅非零色显示，`●n` 点击跳会话页 |
| 主导航 | 图标 + 文字标签；等分四格；当前页高亮 + 下划线/底色（主题定义）；键盘 ←→ 可切换（可达性） |
| 横幅 | 只读错误信息，不遮挡内容；无 warning 时高度为 0 |
| 底栏 | 用量芯片数据来自 usage 线程；时钟本地走秒 |

## 1. 会话页（Sessions）

**目的**：一眼回答「谁需要我」；红灯会话提供倒计时与手动继续。

```text
┌───────────────────────────────────────┐
│ ● webapp                     🔴 12m   │ ← 卡片头：项目名 + 灯 + 空闲
│   用量限额 429 · 限额将在 21:34 重置    │ ← reason 文案（i18n）
│   ↳ 01:23:45 后自动继续 · 已发 1/3     │ ← 倒计时行（每秒本地走秒）
│   in 1.1M · cache 1.2M · out 89K · 42 │ ← 用量 meta（等宽字体）
│   "额度已用尽，限额将在 21:34:12 重置…"│ ← 预览（≤2 行，省略）
│   work:0.1 · pid 4123     [立即继续]  │ ← tmux 位置 · PID · 动作
├───────────────────────────────────────┤
│ ● parser                     🟡 3m    │
│   等待你回答问题（AskUserQuestion）    │
│   "要使用哪种方案？ A 原样保留 B…"     │
│   work:1.2 · pid 5377                 │ ← 黄灯无倒计时无按钮
├───────────────────────────────────────┤
│ ● clawmon                    🔵 5m    │ ← 蓝：回合完成
├───────────────────────────────────────┤
│ ● docs-site                   🟢 8s   │
│   工具运行中 · Bash                   │
├───────────────────────────────────────┤
│ ● scripts                     🟢 2m   │
│   仅监控（不在 tmux 中）               │ ← 绿但不可控
└───────────────────────────────────────┘
```

**数据绑定**：`SessionView{project, state, reason, idleSec, usage,
preview, tmuxLabel, pid, countdown, sends, controllable}`；
`countdown.kind` 前端只做 switch（waiting/capped/off/noTmx），不推导。

**状态与边界**：
- 排序 红→黄→蓝→绿，同色按 PID；列表为空 → 空态 + tmux 引导文案；
- `controllable=false` → 无「立即继续」，倒计时区显示「仅监控」；
- 自动继续关闭 → 显示「已停用」而非「已达上限」（沿用 v0 语义）；
- 任务拉起的会话：卡片右上角出现 `▶ 任务` 徽章，点击跳任务页对应行。

## 2. 任务页（Tasks，v2 新增）

**目的**：把「开终端跑什么」存成一键动作；运行状态一目了然。

```text
┌───────────────────────────────────────┐
│ 任务清单（4）                 [+ 新建] │ ← 页头：计数 + 主按钮
├───────────────────────────────────────┤
│ ▶ 修复登录 bug            ● 运行中 32m │ ← 状态徽章（呼吸动画）
│   ~/work/webapp                        │
│   $ claude "修复登录重定向"             │ ← 命令（等宽，1 行省略）
│   关联会话：● 绿灯 · [查看]            │ ← 跳会话页
│   [打开终端] [停止]                    │
├───────────────────────────────────────┤
│ ▶ 重构解析器              ● 运行中 · 红│
│   ~/clawmon                            │
│   $ claude "重构 detect.py 配对逻辑"   │
│   关联会话：🔴 429 等待 · [查看]       │
│   [打开终端] [停止]                    │
├───────────────────────────────────────┤
│ ▶ 每日构建报告             ○ 待启动    │
│   ~/work/docs · $ make report          │
│   [启动] [编辑] [删除]                 │
├───────────────────────────────────────┤
│ ✓ 依赖升级                 ✓ 已结束    │
│   ~/work/api · 上次 09-24 21:40        │
│   [再次启动] [编辑] [删除]             │
└───────────────────────────────────────┘
```

**新建表单**（页内抽屉/对话框，非跳页）：

```text
┌───────────────────────────────────────┐
│ 新建任务                          [×] │
│ 标题   [修复登录 bug_______________] │
│ 目录   [~/work/webapp______________] │ ← 必须 WSL 绝对路径（/ 或 ~ 开头）
│ 命令   [claude "修复登录重定向"_____] │ ← 等宽输入；支持换行（多命令）
│        例：claude "…" · make test     │
│              [取消]  [保存任务]       │
└───────────────────────────────────────┘
```

**数据绑定**：`TaskView{id,title,cwd,command,status,sessionId?,pid?,
lastRunAt}`；运行中任务的「关联会话」从会话页快照按 sessionName 反查。

**状态与边界**：
- 排序：运行中 → 待启动 → 已结束，同组按 lastRunAt 降序；
- `launching`（启动中）：徽章转圈，按钮全部禁用（防重叠点击，FR10.2）；
- 空态：图 + 「把常用的 claude 任务存成一键启动」+ [新建第一个任务]；
- 「停止」需二次确认（对话框），执行 `tmux kill-session`。

条形为纯 CSS 宽度百分比（无图表库）。

## 4. 设置页（Settings）

**目的**：迁移自 v0 设置面板，内容字段不变（PRD FR8），仅换容器。

```text
┌───────────────────────────────────────┐
│ ▸ 通用                                 │
│   语言 [中文 ▾] · 关闭到托盘 [开关]    │
│   轮询间隔 [5] 秒                      │
│ ▸ 状态判定                             │
│   活跃判定 [120] 秒 · 超时判定 [300] 秒│
│ ▸ 自动继续                             │
│   自动继续 [开关] · 等待 [5] 小时      │
│   按键 [Enter] · 次数 [3] · 重试 [10] 分│
│ ▸ 通知                                 │
│   5 类逐项开关 · 提示音 [开关]         │
│ ▸ 高级                                 │
│   WSL 发行版 [____] · GLM 用量 [开关]  │
│         [还原默认]  [保存]             │
└───────────────────────────────────────┘
```

规则沿用 v0：数字输入 HTML 校验（min/max 对应 Rust sanitize 范围）；
保存后即时生效并广播；tmux 使用提示文案随表单展示。

## 5. 跨页面交互规则

| 规则 | 说明 |
|------|------|
| 导航切换 | 无确认弹窗；设置页有未保存修改时提示（脏检查） |
| 页面间跳转 | 任务↔会话双向（`▶ 任务` / `[查看]` 徽章），跳转后目标行短暂高亮 |
| 数据新鲜度 | 后端推送 `sessions`/`usage` 事件驱动重渲染；页面不各自轮询（FR5.1） |
| 键盘 | ←→ 切导航；Enter 触发焦点按钮；Esc 关闭对话框 |
| 空窗宽 340px | 卡片 meta 行允许折行到两行；预览缩为 1 行；导航标签字号 -1 |
