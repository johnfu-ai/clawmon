| 项目 | 内容 |
|------|------|
| 版本 | 1.0 · 2026-09-25 |
| 结论 | 5 个方向评估，**3 个入选**出原型：A 深色工具风 / B 浅色简约 / C 终端复古 |

## 1. 评估维度（评分 1–5，5 最佳）

| # | 维度 | 为什么重要 |
|---|------|-----------|
| 1 | 数字密度可读性 | 页面主体是 PID、token 数、倒计时等等宽数字，小字号高密度 |
| 2 | 夜间值守适配 | 核心场景是晚上挂机、白天瞄一眼；暗环境刺眼=不可用 |
| 3 | 400px 窄窗适配 | 默认 400×620、最小 340px，横向空间几乎为零 |
| 4 | WebView2 纯 CSS 可实现 | 无构建步骤、无图表库、无运行时依赖的硬约束 |
| 5 | 终端/WSL 身份契合 | 用户是重度终端用户，视觉语言应与之同源 |
| 6 | 实现与维护成本 | 三套风格由同一骨架承载，皮肤差异越大成本越高 |
| 7 | 未来扩展 | 路线图有会话历史/统计页（图表、时间轴） |

## 2. 候选方向

### A. 深色工具风（Slate）——当前视觉的体系化演进

深石板蓝底 + 低饱和面板 + 四色状态光晕，等宽数字。定位：**专业常驻工具**。
延续 v0 用户已习惯的视觉，把零散样式收敛成 token 体系。

### B. 浅色简约（Paper）——白天办公场景

浅灰底 + 纯白卡片 + 细边框 + 软阴影，状态色加深保对比度。定位：
**桌面办公小部件**。与 Windows 11 浅色主题协调，亲和、无威胁感。

### C. 终端复古（CRT）——磷光屏极客风

近黑底 + 磷光绿主色 + 全等宽字体 + 直角 + 细扫描线。定位：**终端原住民的
仪表盘**。与被监控对象（tmux/WSL/claude CLI）视觉同源，身份认同最强。

### D. 玻璃拟态（Acrylic）——Windows 11 原生质感（落选）

半透明面板 + 背景模糊 +  acrylic 材质。

### E. 趣味宠物风（Playful）——Clawd 主导的卡通界面（落选）

大圆角、高饱和、螃蟹吉祥物充斥每个页面。

## 3. 评分与结论

| 维度 | A Slate | B Paper | C CRT | D Acrylic | E Playful |
|------|---------|---------|-------|-----------|-----------|
| 数字密度可读性 | **5** | 4 | **5** | 3 | 2 |
| 夜间值守适配 | **5** | 3 | **5** | 4 | 3 |
| 400px 窄窗适配 | **5** | **5** | 4 | 4 | 3 |
| 纯 CSS 可实现 | **5** | **5** | **5** | 2 | 4 |
| 终端身份契合 | 4 | 2 | **5** | 3 | 3 |
| 实现维护成本 | **5** | **5** | 4 | 2 | 3 |
| 未来扩展 | 4 | 4 | 3 | 3 | 2 |
| **合计（35 满分）** | **33** | **28** | **31** | 21 | 20 |

**入选 A / B / C，出全套原型供选择。**

落选理由（诚实记录）：

- **D Acrylic**：WebView2 里 backdrop-filter 在窗口 resize/滚动时重绘成本
  高且驱动相关；半透明面板上的等宽数字对比度难以稳定达标（维度 1/4 双输）。
  真要 Windows 11 质感，可在任一入选风格上后续加 mica 窗口底，不动组件层。
- **E Playful**：主窗口是高密度数据工具，卡通化直接牺牲可读性；「趣味」
  职责已由桌面宠物独立承担——**宠物负责可爱，主窗负责专业**的分工是刻意
  设计，不合并。

## 4. 三风格并存的工程事实

三套皮肤共享**同一份语义 HTML 与组件结构**，仅换主题 CSS（原型中
`_shared/theme-*.css`，策略模式）。因此选型不改变信息架构与交互，只决定
token 表——**晚选、换选、混合选（如 Paper 底 + Slate 灯色）成本都极低**。

| | A Slate | B Paper | C CRT |
|---|---------|---------|-------|
| 一句话 | 暗夜值守搭档 | 白天办公小部件 | 终端原住民仪表盘 |
| 基调 | #10141a 深石板 | #f4f6f9 浅灰白 | #0a0e0a 磷光黑 |
| 主色 | #6aa1ff 雾蓝 | #2563eb 皇家蓝 | #45f882 磷光绿 |
| 字体 | UI 字体为主，数字等宽 | 同左 | **全等宽** + 大写标签 |
| 圆角 | 8px | 10px | 2px（近直角） |
| 特效 | 状态点光晕、红闪 | 软阴影 | 扫描线、`>` 前缀、终端光晕 |
