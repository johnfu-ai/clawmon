# 设计系统 B — Paper 浅色简约

| 项目 | 内容 |
|------|------|
| 定位 | 桌面办公小部件：白天场景，Windows 11 浅色环境协调 |
| 原型 | `prototypes/paper/`（theme-paper.css） |

---

## 1. 设计原则

1. 白卡片浮在浅灰底上，层级靠**阴影 + 边框**双信号；
2. 状态色在浅底上分两档：**点用亮色，字用深色**（对比度硬约束）；
3. 克制圆角与阴影，整体像一沓便签而不是一箱玩具。

## 2. Design Tokens

### 色彩

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#f4f6f9` | 窗口底 |
| `--panel` | `#ffffff` | 卡片 |
| `--panel-hover` | `#f8fafc` | 卡片悬停 |
| `--border` | `#e3e8ef` | 1px 分隔 |
| `--text` | `#1b2533` | 主文本 |
| `--muted` | `#66738a` | 次要文本 |
| 状态点色 | green `#22c55e` / blue `#3b82f6` / yellow `#f59e0b` / red `#ef4444` | 灯、进度条、图形 |
| 状态文字色 | `#15803d` / `#1d4ed8` / `#b45309` / `#b91c1c` | reason 文案、徽章字 |
| `--accent` | `#2563eb` | 主按钮/链接/active |
| `--accent-ink` | `#ffffff` | accent 上的文字 |
| `--danger-bg` / `--danger-ink` | `#fef2f2` / `#b91c1c` | 横幅/toast |

对比度：text/panel ≈ 14.9:1（AAA）；muted/panel ≈ 4.9:1（AA）；
状态**文字**色均 ≥ 4.5:1（AA）；状态点色仅用于 ≥3px 图形不做文本。

### 字体与字号

与 Slate 同族同字号阶梯（`--font-ui` Segoe UI/MSYH；`--font-mono` Cascadia
Mono/Consolas；11/12/**13**/15），浅底下 muted 降一档灰阶避免发虚。

### 间距 / 圆角 / 层次

| Token | 值 |
|-------|-----|
| spacing | 4 / 8 / 12 / 16 / 24 |
| `--radius` | 10px（卡片）；8px（按钮/输入）；999px（徽章） |
| 卡片阴影 | `0 1px 2px rgba(16,24,40,.06), 0 1px 3px rgba(16,24,40,.10)` |
| 悬浮阴影 | `0 4px 12px rgba(16,24,40,.12)` |
| 状态点 | 无光晕，2px 同色描边环（浅底上光晕脏） |
| 动效 | 150ms ease-out；红灯点 2s 呼吸（透明度而非发光） |

## 3. 组件规范

| 组件 | 规范 |
|------|------|
| 主导航 | 底色 `--panel`、下边框分隔；active 项 accent 文字 + 2px 底条；hover 浅灰底 |
| 顶栏汇总 | `●n` 胶囊用状态**文字**色 + 8% 同色底 |
| 会话卡片 | 白底 + 阴影 + border；红灯卡片左侧 3px red 竖条 + `#fef2f2` 淡红头带 |
| 状态点 | 8px 圆 + 同色环；红灯呼吸（opacity .55→1） |
| 徽章 | 运行中=green 8% 底 + `#15803d` 字；待启动=灰底；已结束=border 底 muted 字 |
| 按钮 | primary=accent 白字；ghost=白底 border；danger=`#fef2f2` 底红字红边 |
| 输入 | 白底 border，focus：accent 边 + `0 0 0 3px rgba(37,99,235,.15)` |
| 开关 | 32×18，开=accent，关=border，白滑块带浅阴影 |
| 进度条 | 6px；轨道 `#e9edf3`，阈值变色同 Slate |
| 倒计时 | 等宽；最后 60s `#b45309` 加粗 |
| 横幅/Toast | `--danger-bg` 底 + 红字 + 1px `#fecaca` 边 |
| 空态 | 居中浅灰图 + muted 文 + 主按钮 |

## 4. 布局骨架

与 Slate 同一骨架（36/40/横幅/滚动/28）；导航栏多了实底与下边框，
内容区底色 `--bg` 使白卡片浮起。

## 5. Do / Don't

- ✅ 图形用亮状态色、文字用深状态色，绝不混用。
- ✅ 阴影只两档（静止/悬浮）。
- ❌ 不用大阴影/多层阴影造「悬浮感」（常驻窗口要安静）。
- ❌ 黄色文字禁止用 `#f59e0b`（白底 2.2:1 不可读）——一律 `#b45309`。
- ❌ 不做暗色状态残留（如半透明黑遮罩）——那是 Slate 的语言。
